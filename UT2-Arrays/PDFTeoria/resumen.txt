Añadir y quitar

push("x") → mete algo al final.
unshift("x") → mete algo al principio.
pop() → quita el último.
shift() → quita el primero.

let a = ["b", "c"];
a.push("d");      // ["b", "c", "d"]
a.unshift("a");   // ["a", "b", "c", "d"]
a.pop();          // ["a", "b", "c"]
a.shift();        // ["b", "c"]

slice vs splice

SLICE(inicio, fin) = FOTOCOPIA un trozo. Saca un trozo a un array nuevo y no toca el original. El fin no entra.

let a = ["a", "b", "c", "d"];
a.slice(1, 3);   // ["b", "c"]
// a sigue siendo ["a", "b", "c", "d"]


SPLICE(posición, cuántosQuitar, lo que quieras meter) = TIJERAS Y PEGAMENTO. Corta y/o pega directamente en el original.

Solo quitar: a.splice(1, 2) → desde la posición 1, quita 2.
Solo insertar: a.splice(2, 0, "x") → en la posición 2, quita 0 y mete “x”.
Reemplazar: a.splice(2, 1, "x") → en la posición 2, quita 1 y mete “x” en su lugar.

let a = ["a", "b", "c", "d"];
a.splice(1, 2);          // quita "b" y "c" → ["a", "d"]
a.splice(1, 0, "x");     // mete "x" en la 1 → ["a", "x", "d"]
a.splice(1, 1, "y");     // cambia "x" por "y" → ["a", "y", "d"]

sort

Ordena el array. Sin nada dentro ordena como texto (no sirve para números). Con función:

javascript
[10, 2, 5].sort((a, b) => a - b);   // [2, 5, 10]  menor a mayor
[10, 2, 5].sort((a, b) => b - a);   // [10, 5, 2]  mayor a menor

split y join (son opuestos)

split("/"): cadena → array. Corta por el separador.

join("-"): array → cadena. Pega con el separador.


"5/3/8".split("/");        // ["5", "3", "8"]
["5", "3", "8"].join("-"); // "5-3-8"

-----------------------------------------------------------------------------------------------------------------------------------------------------------

concat, reverse, indexOf, lastIndexOf

concat: junta dos arrays en uno nuevo.

reverse: le da la vuelta al array.

indexOf("x"): en qué posición está “x” por primera vez (-1 si no está).

lastIndexOf("x"): lo mismo pero la última vez.


[1, 2].concat([3, 4]);          // [1, 2, 3, 4]
[1, 2, 3].reverse();            // [3, 2, 1]
["a", "b", "a"].indexOf("a");     // 0
["a", "b", "a"].lastIndexOf("a"); // 2

-----------------------------------------------------------------------------------------------------------------------------------------------------------

Método	        En una frase	                                                 Ejemplo con [1, 2, 3, 4]
filter	        Te quedas solo con los que cumplen → array nuevo	             .filter(n => n > 2) → [3, 4]
find	        El primero que cumple	                                         .find(n => n > 2) → 3
findIndex	    La posición del primero que cumple	                             .findIndex(n => n > 2) → 2
every	        ¿Cumplen TODOS? → true/false	                                 .every(n => n > 0) → true
some	        ¿Cumple AL MENOS UNO? → true/false	                             .some(n => n > 3) → true
map	            Transforma cada uno → array nuevo	                             .map(n => n * 2) → [2, 4, 6, 8]
reduce	        Resume todo en un solo valor	                                 .reduce((acum, n) => acum + n) → 10
forEach	        Hace algo con cada uno, no devuelve nada	                     .forEach(n => console.log(n))
-----------------------------------------------------------------------------------------------------------------------------------------------------------
find → te devuelve el elemento (el valor).

findIndex → te devuelve la posición donde está ese elemento.

Los dos reciben un callback que responde true o false

let frutas = ["pera", "manzana", "naranja", "melón"];
Quiero buscar la primera fruta que empiece por “m”:
let resultado = frutas.find(fruta => fruta[0] == "m");

fruta = "pera"     → "p" == "m" → false → sigue
fruta = "manzana"  → "m" == "m" → true  → PARA AQUÍ y devuelve "manzana"
fruta = "naranja"  → no llega a mirarse
fruta = "melón"    → no llega a mirarse

Aunque "melón" también empieza por “m”, no lo devuelve, porque find solo da el primero que cumple.

let posicion = frutas.findIndex(fruta => fruta[0] == "m");

posición:    0       1          2         3
valor:    "pera", "manzana", "naranja", "melón"
                     ↑
                  aquí está



Si ningún elemento cumple, el callback da false en todas las vueltas y:

javascript
frutas.find(fruta => fruta[0] == "z");       // undefined
frutas.findIndex(fruta => fruta[0] == "z");  // -1

find devuelve undefined (no hay elemento).
findIndex devuelve -1 (no existe esa posición).

-----------------------------------------------------------------------------------------------------------------------------------------------------------
filter: “quédate solo con los que cumplan”

El callback tiene que devolver true (el elemento se queda) o false (se descarta).
let numeros = [1, 2, 3, 4, 5];
let grandes = numeros.filter(n => n > 2);

Lo que pasa vuelta a vuelta:

n = 1 → 1 > 2 → false → se descarta
n = 2 → 2 > 2 → false → se descarta
n = 3 → 3 > 2 → true  → SE QUEDA
n = 4 → 4 > 2 → true  → SE QUEDA
n = 5 → 5 > 2 → true  → SE QUEDA
grandes = [3, 4, 5]

-----------------------------------------------------------------------------------------------------------------------------------------------------------
map: “transforma cada uno”

Aquí el callback no devuelve true/false, devuelve el valor nuevo que quieres en su lugar.

let numeros = [1, 2, 3];
let dobles = numeros.map(n => n * 2);
n = 1 → 1 * 2 → 2
n = 2 → 2 * 2 → 4
n = 3 → 3 * 2 → 6
dobles = [2, 4, 6]

-----------------------------------------------------------------------------------------------------------------------------------------------------------
every y some: “¿cumplen todos?” / “¿cumple alguno?”

Callback con true/false, y el método devuelve un solo true/false.

javascript
let numeros = [1, 2, 3, 4];

numeros.every(n => n > 0);   // true  (todos son mayores que 0)
numeros.every(n => n > 2);   // false (el 1 y el 2 no cumplen)
numeros.some(n => n > 3);    // true  (el 4 cumple)
numeros.some(n => n > 10);   // false (ninguno cumple)

-----------------------------------------------------------------------------------------------------------------------------------------------------------
reduce: “resume todo en un solo valor”

Es el más raro. El callback recibe dos cosas:

acum (valor anterior): lo que llevas acumulado.
n (valor actual): el elemento que toca ahora.

Y lo que devuelva el callback pasa a ser el acum de la siguiente vuelta.

javascript
let numeros = [1, 2, 3, 4];
let suma = numeros.reduce((acum, n) => acum + n);

Sin valor inicial, acum empieza siendo el primer elemento y n el segundo:

vuelta 1: acum = 1, n = 2 → devuelve 1 + 2 = 3
vuelta 2: acum = 3, n = 3 → devuelve 3 + 3 = 6
vuelta 3: acum = 6, n = 4 → devuelve 6 + 4 = 10
